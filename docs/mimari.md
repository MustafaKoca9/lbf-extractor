# Mimari

Herkese açık Python API, isteğe bağlı CLI arayüzünden ayrıdır. Modüller: common (ortak sabitler ve modeller), archive (çok parçalı akış), metadata (başlık ve şifre çözme), paths (çıktı yolu güvenliği), extraction (akışla dosya yazma), diagnostics (makine tarafından okunabilir rapor), reporting (denetim özeti), core (işlem hattı), cli (argüman ayrıştırma). Dosyaları çıkarmadan ham XML, özgün alanlar, yorumlanan ofset/boyutlar, çözülemeyen _CG_ referansları ve tanılamaları incelemek için --metadata-only kullanın. Sınırları geçerli bir ofset yine de anlamsal olarak yanlış yorumlanmış olabilir. Raporları paylaşmadan önce kişisel verileri temizleyin. API chunk_size bayt, CLI --chunk-size-mib MiB cinsindendir.
