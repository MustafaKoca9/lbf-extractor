# Architecture

The public Python API is separate from the optional CLI. Modules: common (constants and models), archive (multipart stream), metadata (header and decryption), paths (output confinement), extraction (stream writes), diagnostics (machine-readable reports), reporting (audit summary), core (pipeline), cli (argument parsing). Run with --metadata-only to inspect raw XML, original fields, parsed offsets/sizes, unresolved _CG_ references, and diagnostics without extracting payload files. Structurally valid offsets may still be semantically misinterpreted. Redact personal data before sharing. API chunk_size is bytes; CLI --chunk-size-mib is MiB.
